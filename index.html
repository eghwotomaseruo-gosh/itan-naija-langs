Setting Up Google Sign-In

To enable 1-click Google Sign-In on this domain, add your Google OAuth credentials to your server environment:

1. Your Authorized Redirect URI

https://your-domain/auth/google/callback

Add this URL to Authorized redirect URIs in your Google Cloud Console Credentials.

2. Environment Variables to Set

In Render Dashboard (or AI Studio Settings), add these 2 environment variables:

  • GOOGLE_CLIENT_ID
  • GOOGLE_CLIENT_SECRET
